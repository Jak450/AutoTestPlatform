# AutoTestPlatform 前端重设计 · 设计文档

> 日期：2026-08-10
> 状态：已确认（用户已批准方向）
> 依据：与用户的头脑风暴结论（范围 A：全站重做；场景 C：效率优先 + 好看；技术 C：混合方案；视觉 B：浅色蓝图；布局 B：顶部导航；仅浅色）

## 1. 背景与目标

现有前端（Vue 3 + Element Plus）功能完整但视觉停留在 Element 默认质感，页面缺乏统一的设计语言。本次目标：

- 建立一套有辨识度的设计系统（Token / 排版 / 组件），不再有"模板味"；
- 全站 10 个页面统一套用，保持每日使用效率（信息密度、操作路径）；
- 技术风险可控：门面自建，数据密集组件（表格/表单/弹窗）用 Element Plus 深度换肤。

## 2. 设计方向：AutoTest · Blueprint（浅色蓝图）

主题来自"工程图纸/测试蓝图"的意象：蓝图蓝、细网格、等宽数据、状态图章。

### 2.1 设计 Token

| Token | 值 | 用途 |
|---|---|---|
| `--canvas` | `#F6F7F9` | 全局画布底色 |
| `--grid` | `rgba(36,86,230,.05)`，18px 网格 | 画布细网格纹理 |
| `--panel` | `#FFFFFF` | 卡片/面板 |
| `--line` | `#DDE4F0` | hairline 描边 |
| `--primary` | `#2456E6` | 蓝图蓝（主操作/链接/运行态） |
| `--primary-soft` | `#E8EEFA` | 主色浅底（选中/hover/AI 气泡） |
| `--ink-strong` | `#17233B` | 标题 |
| `--ink-body` | `#3D4A63` | 正文 |
| `--ink-muted` | `#7B879E` | 弱化文字/占位 |
| `--success` | `#1F9D55` | 通过 |
| `--danger` | `#DC2626` | 失败/删除 |
| `--warning` | `#D97706` | 警告/待确认 |
| `--mono-ink` | `#1E293B` | 等宽文字（数据） |

圆角：卡片 4px、按钮 6px、输入框 6px、气泡 8px。阴影：极轻（`0 1px 3px rgba(23,35,59,.06)`）。

### 2.2 字体

- 标题/展示：**Sora**（600/700，字距 -0.3px）
- 正文：**Inter**（400/500）
- 数据/日志/URL/状态：**IBM Plex Mono**（400/500，12-13px）
- 字体通过 npm fontsource 包自托管，不依赖外网 CDN。

字号阶梯：页面标题 20-24 / 区块标题 16-17 / 正文 14 / 辅助 12 / 数据 mono 12-13。

### 2.3 签名元素

1. **状态图章**：通过/失败/跳过 渲染为"盖章式"徽章（mono 大写 + 印章描边 + 轻微旋转 1°）；运行中为蓝图蓝呼吸圆点。
2. **图纸网格**：画布细网格背景贯穿所有页面，形成"在看一张活的工程图纸"的质感。

## 3. 布局与导航（顶部导航）

- **顶栏**（高 56px，白底 + 底部 hairline）：
  - 左侧：蓝图方块 Logo（8px 圆角 `#2456E6` 方块 + 内部网格）+ `AutoTest·Spec` 字标（Sora 600）
  - 中间：主导航——AI Agent / 接口测试（下拉：项目管理/用例管理/API测试/批量执行）/ UI 测试（下拉：UI测试工作台/UI项目管理/UI用例管理/UI批量执行）/ 报告 / AI 需求分析
  - 右侧：当前用户（displayName）+ 退出菜单
  - 窄屏（<960px）：导航收进汉堡抽屉
- **页面容器**：`--canvas` + 网格背景；内容区最大宽度不限（工具类页面全宽），padding 24px
- **页面标题条**：页面标题（Sora 20）+ 面包屑/上下文说明（可选）+ 右侧主操作按钮（实心蓝）

## 4. 页面规范

### 4.1 登录页（自建）

- 满屏画布网格背景；左侧品牌区：蓝图方块 + `AutoTest·Spec` 大号字标 + 一句说明；右侧居中白色卡片表单
- 表单：用户名 / 密码（Inter 14），登录按钮全宽实心蓝；错误提示用 `--danger`

### 4.2 AI Agent 页（自建，重点）

- 三栏：
  - **会话列表**（宽 240px，白底 hairline 右描边）：新建会话按钮（虚线框）、会话项（当前项左侧 3px 蓝图蓝条 + `--primary-soft` 底）
  - **对话流**（flex:1，网格画布）：用户气泡右对齐白底蓝图描边；AI 气泡左对齐 `--primary-soft` 底；系统/错误用 `--danger` 弱化；消息间 16px 间距
  - **资源面板**（宽 280px，可折叠）：文件 / 模板 / 记忆 三个分组，头部 mono 小标签
- 消息类型渲染：
  - `text`：气泡
  - `file`：文档行（📄 + mono 文件名）
  - `tool_call`：执行时间线卡片（mono：工具名 + 状态图章 + 耗时，左侧 3px 状态色条）
  - `confirmation`：确认卡（`--warning` 琥珀描边 + 白底，批准/拒绝按钮）
  - `case_preview`：用例预览表格（hairline 表格 + 方法徽章）
- 输入区：底部白底 hairline 上描边；左侧上传按钮（图标），中间圆角 textarea，右侧实心蓝"发送"；发送中按钮态 + 停止按钮
- 流式输出：保持现有 SSE 增量渲染，气泡文字逐 token 追加，光标处淡入

### 4.3 数据管理页（Element Plus 深度换肤）

- **项目管理**：白卡网格（卡片 = 面板 + hairline + hover 抬升）；新建/编辑用对话框
- **用例管理**：hairline 表格（表头 mono 12 弱化色，行 hover `--primary-soft` 30%）；HTTP 方法徽章：GET 蓝 / POST 绿 / PUT 琥珀 / DELETE 红 / PATCH 紫；URL mono
- **API 测试工作台**：左请求配置（方法徽章选择 + URL 输入 + tabs：参数/请求头/断言）右响应面板（大号状态码 + mono 响应体 + 断言结果列表）
- **批量执行**：顶部统计卡 ×4（总数/通过/失败/总耗时，数字 Sora 24 + mono 单位）+ 结果表格（状态图章 + mono 耗时）
- **报告**：筛选栏（模块/用例/状态/时间）+ 表格 + AI 分析按钮 + Allure 导出
- **UI 系列**（工作台/项目/用例/批量）：与 API 侧同构；steps 用 mono 展示步骤动作

## 5. 组件策略（混合）

**自建组件**：TopNav、Logo、PageHeader、StatusStamp（状态图章）、StatCard、Agent 会话/对话/工具卡/确认卡/预览表、文件行、EmptyState、网格画布容器。

**Element Plus 换肤**（通过 CSS 变量覆盖 + 组件级样式覆盖）：
- `el-table`：去默认边框 → hairline，表头 mono 弱化，行 hover 浅蓝
- `el-button`：primary 实心蓝、圆角 6px、hover 加深
- `el-dialog`：白面板 hairline 顶边、标题 Sora 16
- `el-form/input/select`：圆角 6px、聚焦描边 `--primary`
- `el-tag`：状态/方法徽章样式

## 6. 动效与质感

- 运行状态呼吸点（1.6s 循环，仅运行中）
- 表格行 hover、卡片 hover 抬升 1px
- 路由切换 160ms 淡入
- 遵守 `prefers-reduced-motion`；键盘焦点可见（2px `--primary` 焦点环）

## 7. 实施阶段（写入实现计划后细化）

1. **设计基建**：CSS 变量文件、全局 reset、网格画布、字体包接入、TopNav + 布局重构（App.vue）、登录页
2. **Agent 页重做**：三栏布局 + 全部消息类型组件 + 资源面板
3. **数据页套用**：项目/用例/API 工作台/批量/报告/UI 系列逐页换肤与微重构
4. **收尾**：空状态、错误态、响应式、动效、构建与回归验证

## 8. 验收标准

- 10 个页面视觉统一，无 Element 默认感残留（表格/按钮/对话框）
- Agent 页流式对话、工具卡片、确认卡、用例预览在重做后功能不回退
- 顶部导航全部路由可达，窄屏可折叠
- `npm run build` 通过；后端接口不受影响
